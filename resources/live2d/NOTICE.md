# Live2D POC asset notice

This directory contains a local-only technical proof of concept for the
Whale Companion renderer. It is not a XiaoJing skin and must not be presented
as an official or default character asset.

## Arch-chan model

- Origin: https://github.com/Speykious/arch-chan
- Pinned source revision: `ed43dcf7e88d56f79d2e42fecb084bf6923f44e0`
- License: CC0 1.0 Universal. The source `LICENSE.md` is copied verbatim to
  `arch-chan/LICENSE.md`.
- Included runtime files: the model manifest, `.moc3`, texture, physics,
  display-info and expression referenced by the manifest.
- `arch-chan/motions/*.motion3.json` are project-authored regression motions,
  added to the CC0 model for state-engine testing. They drive only parameter
  IDs declared by the model and are not sourced from an external character.
  The three loop files are deterministically generated by the project-local
  Node tooling under `tools/live2d-motion/`; their provenance and MIT notice
  are recorded in `tools/live2d-motion/UPSTREAM.md` and `LICENSE`.
- Intentionally excluded: `cmo3/Arch Chan Model0.cmo3`, which is the editable
  Cubism authoring source and is not required by the renderer.
