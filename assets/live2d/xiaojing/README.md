# 小鲸 Live2D 原画母版

这里存放的是小鲸的原创美术母版，供后续人工分层、Cubism 建模和运行时接入使用。它们不是可直接播放的 Live2D 模型，也不会被应用自动加载。

| 文件 | 用途 | 状态 |
| --- | --- | --- |
| `xiaojing-cubism-master-v1.png` | 早期坐姿探索稿 | 保留，不进入建模 |
| `xiaojing-standing-master-v3.png` | 第一张站姿比例探索稿 | 保留，不进入建模 |
| `xiaojing-standing-master-v4.png` | 站姿、面部语言与上身比例候选 | 等待视觉确认后进入分层 |

`v4` 的设计目标是让小鲸在桌面小尺寸下仍然读得清：蓝发、呆毛、鲸鳍耳、尾鳍、蓝白女仆结构和潮汐蓝宝石是她自己的识别点。她采用小圆颊、小下巴、深色上睫和蓝色渐变瞳的面部语言，同时保持更宽的肩线、完整的上身量感和可读的尾鳍连接。外部鲸鱼娘二创只作为轮廓和配色研究，不能复制其人物、图案或作者笔触，也不会作为程序资产发布。

## 分层目标

在开始建模前，先从确认后的母版制作一份修补完成的分层 PSD。每个可动和遮挡区域必须有被遮挡部分的补绘，不能依赖这张合成 PNG 直接自动拆层。

```text
00_reference                 仅供对照，导出时隐藏
01_body_base                 皮肤、颈部、腿部和鞋
02_face_base                 脸型、鼻口区域
03_eye_left / eye_right      白眼、虹膜、高光、上眼皮、下眼皮、睫毛分开
04_brow_left / brow_right
05_mouth                     嘴唇、口内、舌头分开
06_hair_back                 后发和两侧大束发
07_hair_front                刘海、侧发和呆毛分开
08_headwear                  女仆头饰和发夹
09_fin_ears                  左右鲸鳍耳，含内侧
10_torso                     衬衣、马甲、领结、宝石胸针
11_arm_left / arm_right      袖、手臂、手分开，保留被头发和裙摆遮挡的部分
12_apron                     围裙主体和荷叶边
13_skirt_front / skirt_back  裙摆前后层和主要褶皱
14_tail                      尾柄、左右尾鳍和高光分开
15_fx                        仅放可选的潮汐微光，不放背景或投影
```

## 进入建模的门槛

1. 母版已确认肩线、眼睛比例、上身量感、尾鳍连接和全身轮廓。
2. PSD 中的眼睛、嘴、前后发、手臂、裙摆和尾鳍均有独立层及遮挡补绘。
3. 导出 `.moc3` 和 `.model3.json` 后，必须通过 `npm run live2d:check` 与发布自检。
4. 在小鲸窗口以 160 至 320 px 实测待机、眨眼、说话和鼠标悬停，不通过时回到分层或参数修正。
