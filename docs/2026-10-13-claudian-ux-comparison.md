# 小鲸与 Real Claudian 的体验差距（2026-10-13）

## 对照范围

- 小鲸：2026-10-16 以本机 v0.0.62 源码和已打包程序复核差距；下文各批次的版本与验收记录是历史交付，不代替当前代码状态。v0.0.62 可见点击仍待用户验收。
- Claudian：项目内 `reference/claudian` 提交 `981a5e8`，源码版本 `2.3.16`。Obsidian 中安装的插件是 `2.2.4`，下表以源码镜像为准。
- 本文是代码和文档对照，未启动可见界面；动画、布局和实际点击手感待用户验收。详细来源索引见 [既有借鉴清单](./2026-10-10-claudian-borrow-list.md)。

## 第一批实施状态与验收重点

本批已接通发送失败恢复、`@` 文件/目录/会话、`$` 技能候选、工具入参二级折叠和会话搜索反馈。v0.0.50 初稿没有启用；其后审查修复了多会话提交和持久引用，最终 v0.0.51 包已通过类型检查、全量测试、构建与 asar 核对。尚未启动本批可见界面，点击体验待用户验收。连续编号的点击清单见 [交付记录](./2026-10-09-pending-features.md)。

1. 发送未决时切到其他会话，若发送失败，原消息、附件只回到原会话；用户后来输入的内容仍在。
2. 目标创建失败时，目标文字仍可编辑并重新发送；中文输入法组合期间按 Escape 不误收起输入。
3. 输入 `$` 能找到技能，`/` 只列命令；单独输入 `@` 可看到最近文件、目录和会话，选中后实际引用正确对象。
4. 展开工具卡时先看结果，完整入参只在再次展开时出现；鼠标和键盘都能操作，长 JSON 可滚动并可选中复制。
5. 会话搜索等待时只显示加载状态，返回空结果才显示无匹配；切换关键词或归档分类后不出现旧结果。
6. 可见界面的菜单位置、焦点、滚动和动画由用户点击验收。

## 第二批实施状态与下一步

v0.0.52 新增会话栏分组与搜索命中预览。旧版交付说明曾把放大态描述为并列侧栏；复核当前 v0.0.61 源码，实际仍是覆盖聊天的浮动抽屉，因此真正的并列阅读和可调宽度继续列为待做。连续编号的验收 68 至 70 见 [交付记录](./2026-10-09-pending-features.md)，其中 68 的布局描述需以当前源码更正；可见界面的手感由用户点击验收。

## 第三批实施状态与下一步

v0.0.53 在现有会话栏加入多选、批量置顶/归档/恢复/永久删除与逐项跳过反馈；连续编号的验收 71 至 73 见 [交付记录](./2026-10-09-pending-features.md)。可见界面尚未启动，点击手感待用户验收。

v0.0.61 已把同窗口临时侧聊接入主进程与气泡：背景只取主线已结算的可见对话；Claude 侧聊不持久化 SDK transcript，失去热查询后以有界历史重放。`/side`、`/btw` 需附带问题或附件，只有空命令会保留草稿；主线运行中也可开启。该版只有一条侧聊，切换主会话便丢弃，是已记录的历史限制。

v0.0.62 已把侧聊归属改为每个主会话标签各自保留：切标签不停止已启动的侧聊，后台完成后的结果仍归原标签。忙碌侧聊会阻止归档或删除所属主会话；侧聊空闲后随主会话归档或删除而释放，应用退出时全部丢弃。主线与每条侧聊的草稿、附件和展开状态也分别保存；类型检查、全量测试、构建与打包已通过，可见点击见[第十二轮交付记录](./2026-10-09-pending-features.md)。原生 checkpoint 分叉、可调双栏、可编辑引用 chip 与多后端原生接入仍在差距表中。[旧版冷复制设计](./2026-10-14-conversation-fork-design.md)仅供追溯，v0.0.59 已移除该入口。
