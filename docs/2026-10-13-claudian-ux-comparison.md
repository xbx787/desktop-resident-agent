# 小鲸与 Real Claudian 的体验差距（2026-10-13）

## 对照范围

- 小鲸：本轮以本机 v0.0.54 源码复核；v0.0.51 至 v0.0.54 的实现均以当前代码为准，旧版交付说明不能代替实际布局与运行状态。
- Claudian：项目内 `reference/claudian` 提交 `981a5e8`，源码版本 `2.3.16`。Obsidian 中安装的插件是 `2.2.4`，下表以源码镜像为准。
- 本文是代码和文档对照，未启动可见界面；动画、布局和实际点击手感待用户验收。详细来源索引见 [既有借鉴清单](./2026-10-10-claudian-borrow-list.md)。

## 差距与取舍

| 体验 | 小鲸当前源码 | Claudian 做法 | 状态与顺序 |
| --- | --- | --- | --- |
| 标签与会话库 | 顶部标签、拖动排序、搜索、置顶、重命名、归档和删除已具备 | 标签与会话管理并存 | 保留现有入口，不重做 |
| 队列与过程 | 排队、介入、编辑与移除待发消息；思考和工具可折叠，工具卡可按需展开完整入参 | 工具卡按需展示具体参数和结果 | 基础过程展示已实现，细分工具正文仍可借鉴 |
| 发送失败恢复 | 发送归属绑定原会话；失败时把原文与之后输入合并、附件去重，切会话后只回原会话；不同会话可同时提交 | 按提交目的地保存草稿，失败时合并恢复 | **E55 源码与测试已覆盖，点击待验** |
| `/` 与 `$` | `/` 只列命令，`$` 只列技能；后端把已选技能转为 SDK 原生命令 | 分别发现命令和技能 | **E57 源码与测试已覆盖，点击待验** |
| `@` 引用 | 裸 `@` 展示近期文件、目录和可引用会话；文件/目录受工作区边界和读取预算约束，会话以有界快照提供上下文，DeepSeek 最近 20 条历史内可继续追问 | 文件、目录、会话引用，最近项目优先 | **E56 源码与测试已覆盖，点击待验**；输入内 chip 暂未做 |
| 会话搜索反馈 | 搜索等待、结果为空与失败分开提示；迟到结果不能覆盖新关键词或归档分类，新消息更新后重查。旧消息命中显示短片段，工具/敏感内容只显示通用提示 | 结果确定后才显示无匹配状态，命中位置可辨认 | **E59、E62 自动化测试通过，点击待验** |
| 会话浏览 | 小窗与放大态均为覆盖聊天的浮动抽屉；放大态增加日期分组，列表可多选并批量操作 | 大屏可调双栏，分组和批量操作 | 列表管理已有；真正并列和拖拽调宽未实现，需先确定更宽的阅读态，不能沿用旧文档的「已完成」判断 |
| 临时探索 | 没有独立于主会话的 side chat | 多轮临时侧聊，不污染主线 | 第三批，保留同一窗口 |
| 历史节点 | 可引用或删除整轮；当前代码还支持从最新完成回复复制历史到独立会话续聊 | 可预览回退、从旧节点原生分叉及分支导航 | 最新回复冷复制已实现；任意旧节点、原生 checkpoint 和文件回退未实现 |
| 富输入 | 普通 textarea 与附件 chip | 可编辑 `@`、命令 chip | 后续评估输入内核改造 |
| 多执行后端 | 多厂商模型沿用 Claude SDK 兼容路径 | Claude、Codex、Grok、OpenCode、Pi 原生通道 | 后续架构阶段 |

小鲸的角色本体、蓝色简洁气泡、独立设置窗口和现有人设是产品入口，Claudian 的 Obsidian 侧栏外壳不适合直接移植。

## 第一批实施状态与验收重点

本批已接通发送失败恢复、`@` 文件/目录/会话、`$` 技能候选、工具入参二级折叠和会话搜索反馈。v0.0.50 初稿没有启用；其后审查修复了多会话提交和持久引用，最终 v0.0.51 包已通过类型检查、全量测试、构建与 asar 核对。尚未启动本批可见界面，点击体验待用户验收。连续编号的点击清单见 [交付记录](./2026-10-09-pending-features.md)。

1. 发送未决时切到其他会话，若发送失败，原消息、附件只回到原会话；用户后来输入的内容仍在。
2. 目标创建失败时，目标文字仍可编辑并重新发送；中文输入法组合期间按 Escape 不误收起输入。
3. 输入 `$` 能找到技能，`/` 只列命令；单独输入 `@` 可看到最近文件、目录和会话，选中后实际引用正确对象。
4. 展开工具卡时先看结果，完整入参只在再次展开时出现；鼠标和键盘都能操作，长 JSON 可滚动并可选中复制。
5. 会话搜索等待时只显示加载状态，返回空结果才显示无匹配；切换关键词或归档分类后不出现旧结果。
6. 可见界面的菜单位置、焦点、滚动和动画由用户点击验收。

## 第二批实施状态与下一步

v0.0.52 新增会话栏分组与搜索命中预览。旧版交付说明曾把放大态描述为并列侧栏；本轮复核 v0.0.54 源码，实际仍是覆盖聊天的浮动抽屉，因此真正的并列阅读和可调宽度继续列为待做。连续编号的验收 68 至 70 见 [交付记录](./2026-10-09-pending-features.md)，其中 68 的布局描述需以当前源码更正；可见界面的手感由用户点击验收。

## 第三批实施状态与下一步

v0.0.53 在现有会话栏加入多选、批量置顶/归档/恢复/永久删除与逐项跳过反馈；连续编号的验收 71 至 73 见 [交付记录](./2026-10-09-pending-features.md)。可见界面尚未启动，点击手感待用户验收。

下一步优先考虑独立临时侧聊：它需要独立运行时和草稿，折叠后输入归回主会话，不能把临时历史写入主会话库。最新回复冷复制续聊已经落在当前源码中，边界见 [会话分支设计](./2026-10-14-conversation-fork-design.md)；它不具备 Claudian 的原生 checkpoint 分支。任意旧节点、可调双栏、可编辑引用 chip 与多后端原生接入仍在差距表中。
