# 桌面 Agent UI 工程标准（2026-10-08）

## 目标与来源

界面由桌面角色和依附角色的一个气泡组成。角色是常驻入口，气泡是聊天、会话库和工作状态的唯一主界面。保持蓝色、透明、轻量，不放窗口标题或解释性口号。功能可以丰富，默认视图必须安静。

参考 Claudian 的[会话浏览器](https://github.com/YishenTu/claudian/blob/main/src/features/chat/session-manager/SessionBrowser.ts)、[会话操作](https://github.com/YishenTu/claudian/blob/main/src/features/chat/session-manager/SessionActions.ts)、[输入工具栏](https://github.com/YishenTu/claudian/blob/main/src/features/chat/composer/toolbar/InputToolbar.ts)、[上下文环](https://github.com/YishenTu/claudian/blob/main/src/features/chat/composer/toolbar/ContextUsageMeter.ts)和[队列提示](https://github.com/YishenTu/claudian/blob/main/src/features/chat/composer/QueueStrip.ts)。沿用其信息架构和交互思想，组件、视觉和快捷键按本产品的桌面气泡重做，不直接复制 Obsidian 代码。

## 已确认的产品约束

1. **会话数量不限。**“5”只表示放大视图底部默认展示最近 5 个快速切换标签，不限制会话库数量；创建、恢复不因数量而禁用。设置中删除“最多活跃会话”项目及对应拦截。
2. 气泡随角色显示或消失，角色位置始终不动。角色右键和 Windows 托盘图标共用同一份 Electron 原生菜单，菜单跟随鼠标，承载“选项”和“退出”。气泡内部没有设置入口。
3. 气泡右上角两个无文字图标按 Windows 次序排列：左侧放大/还原，最右侧关闭。关闭隐藏整个聊天气泡，桌面角色仍在；退出应用只在角色右键菜单。输入框自身另有一个放大/还原图标，调整输入区域高度，不改变气泡窗口尺寸。
4. 输入工具栏的加号是**新建会话**。文件添加有独立回形针图标，也可拖入、粘贴或用 `Ctrl+O`；不能让加号同时承担两个含义。模型按钮只显示图标。
5. 录音按钮从当前 UI 移除；不删除语音后端代码，后续语音入口单独设计。
6. 会话库标题“会话”的左边是返回箭头。新建、重命名、归档、恢复、删除均用图标，悬停显示名称；删除需要二次确认，键盘与屏幕阅读器也有名称。

## 信息架构

```text
桌面角色 ── 左键 ── 气泡 / 收起气泡
         ├─ 右键 ── 跟随鼠标的原生菜单：选项 · 退出
         └─ 中键 ── DeepSeek 余额 / 峰谷时间

气泡 ── 对话视图 ── 消息流 / 工具活动 / 队列 / 输入区
     ├─ 会话库 ── 搜索 / 未归档 / 已归档 / 会话行操作
     └─ 放大视图底部 ── 最近 5 个会话快速切换标签

选项 ── 角色右键进入 ── 模型与 MCP / 自动归档 / 外观 / 快捷键等
```

“未归档”显示所有未归档会话；“已归档”显示归档会话。列表可滚动、搜索和分批渲染。快速切换条默认显示最近 5 个未归档会话，当前会话必须在可见集合内；更多会话由会话库访问。放大状态才展示切换条，普通气泡不给它固定占一行。

## 空间、窗口和命中区域

| 区域 | 常态 | 放大态 | 约束 |
| --- | --- | --- | --- |
| 角色 | 约 160 × 180 CSS px | 同左 | CSS 的 `right: 8px; bottom: 6px` 为视觉锚点；改变气泡时不重新计算角色视觉坐标 |
| 气泡 | 约 356 × 358 px | 宽约 534 px，高度向工作区顶部延伸 | 左扩、上扩，尾部相对角色不漂移；靠近屏幕边缘时钳制到当前显示器 `workArea` |
| 顶角操作 | 32 × 32 px 命中框，8 px 间距 | 同左 | 放大在左、关闭在右；纯图标悬停显 tooltip；不生成整条标题栏 |
| 输入区 | 默认收起，展开后约 116–160 px | 可单独放高至气泡高度的约 40%，上限 280 px | 有消息时由消息流让出空间；最小空白气泡首次放大输入会恢复常态气泡高度，角色不移动 |
| 快速切换条 | 隐藏 | 输入区上方一行，最多 5 项 | 只影响消息流可用高度，不改变窗口边界 |

Electron 透明窗口的 `setShape` 必须与实际可交互区域一致。气泡隐藏后，其旧位置必须透传鼠标；原生菜单由系统处理，不能再用透明窗口画一份菜单或为菜单扩大 `setShape`。缩放、DPI、拖动后，先完成窗口 bounds 与 shape，再让 CSS 显示新状态，避免闪现旧背景或角色跳动。动画只施加给气泡内部，不对整张角色图片做位移。余额卡片在角色正左侧、垂直居中；显示余额时扩大透明窗口左侧空间，角色屏幕坐标保持不动，卡片与角色留 8 px 间距。

| 气泡左上 | 会话/历史 | 进入会话库 | 会话库 |
| 气泡右上左 | 放大/还原 | 切换气泡尺寸 | 放大对话 / 还原对话 |

| 输入区左下 | 模型符号 | 打开模型与上下文弹层 | 模型与上下文 |
| 输入区左下 | 回形针 | 选择文本文件；同时支持拖入、粘贴及 `Ctrl+O` | 添加文件 |

气泡右上两个控件保持可见，其位置不随对话、会话库、弹层切换。会话列表中的操作图标可在悬停或键盘聚焦行时显现；触摸/键盘环境保留可访问入口。重命名的编辑行保留确认与取消图标；删除确认文本明确指出永久删除及会话标题，确认按钮可用图标但 `aria-label` 须完整。

## 模型与上下文弹层

模型按钮仅有 16–18 px 图标。弹层从按钮上方自然出现，宽度约 220–260 px，内容依次为：当前模型和可选模型、上下文“已用 / 剩余”（百分比及 token）、手动“压缩上下文”按钮。按钮文案可写“压缩”，发送到 Agent 的内部指令是 `/compact`，但 UI 不向用户暴露命令语法。弹层内模型选项保留不可用原因；不要在主工具栏重复模型文字。

上下文环位于底部操作排最右侧的**状态位**，紧靠发送/停止键左边。环只表示当前会话、当前模型的实测用量，不跨会话复用。如果 SDK 尚未给出可信数字，显示空心细环，悬停显示“上下文用量暂不可读取”；禁止造一个估计百分比。0–59% 用淡蓝，60–69% 用亮蓝，70% 及以上显示正在压缩状态；压缩失败用克制的暖色，并在弹层提供明确处理入口。

后台必须在发送前计算可用上下文预算：`剩余 = 窗口上限 - 已用 - 本次输入估算 - 保留输出与工具调用预算`。接近 70% 时先自动压缩，刷新用量后再发；无法压缩且预算不足时阻止本次请求，保留草稿和附件，提示继续压缩或开新对话。不能让用户以盲发承担超上下文错误。百分比与 token 必须标注来源和采样时机，流式执行中允许显示“更新中”。

## 输入和任务状态

| 状态 | 主按钮 | Enter | Ctrl+Enter | 草稿 |
| --- | --- | --- | --- | --- |
| 空闲、有内容 | 发送 | 发送 | 发送 | 受理后清空 |
| 运行、有内容 | 发送 | 加入队列 | 在当前执行的安全阶段插入引导；等待阶段边界，不能仅中断后重发 | 受理后清空 |
| 运行、无内容 | 停止 | 无动作 | 无动作 | 保持空 |
| 压缩中 | 禁用并显示进度 | 暂不发送 | 暂不发送 | 原样保留 |
| 上下文不足 | 禁用并提示处理 | 暂不发送 | 暂不发送 | 原样保留 |

Shift+Enter 换行；IME 组合输入的 Enter 不发送；Escape 按层级先关闭弹层/确认，再收起输入区。运行中的排队消息可在输入区上方看到摘要、编辑和丢弃；工具活动在消息流内以可折叠记录呈现，默认仅展示关键结果。文件拖放、粘贴、`@` 引用进入输入上下文，已附文件用紧凑 chip 显示，删除 chip 只移除该附件。不同会话的草稿与上下文用量独立。

输入开头的 `/` 显示 Claude Code 命令和技能候选；单词边界后的 `@` 搜索当前工作目录下的文件。候选最多 8 条，按上下键移动、Enter 插入、Esc 关闭，鼠标可选。选中命令保留原 `/name` 文本供后端 SDK 执行；文件插入 `@{相对路径}`，含空格的路径用引号。若没有候选，Enter 按正常发送处理；邮箱中的 `@` 和普通句子中的 `/` 不触发。

## 视觉和动效

- 气泡底色使用深海蓝半透明层，参照角色发色；亮部为低饱和雾蓝。边框 1 px、圆角 16–18 px。去掉明显的大块投影和泛绿高光；角色素材始终透明。
- 字号全应用只允许四档：**正文 13 / 主 UI 11 / 辅助 10 / 微标 9**；窗口标题 16、余额大数字 27 为仅有的两个展示档；字符图标（✓ × ✎ ⚠）的 px 是图形尺寸、不受字号规范约束。每个窗口根容器都带 11 px 基准，未声明字号的文字落在基准上，禁止裸奔到浏览器默认 16 px；中间值（10.5、12 等）由 `test/renderer-font-scale.test.ts` 拦截（2026-10-10 收口）。中文优先 `Microsoft YaHei UI`，时间/版本/数字用 Bahnschrift 等宽数字。消息可选择、可复制，Markdown 和块级公式在独立块中完整排版。
- 图标统一 16–18 px 的 1.6–1.8 px 线宽；交互命中框至少 30 × 30 px。单色图标，选中态通过底色/细线区分，不靠闪烁。
- 气泡出现用 160–200 ms 的透明度与 4–6 px 微位移；弹层 120–160 ms。角色自身点击不位移、不滤镜闪烁。`prefers-reduced-motion` 关闭非必要动画。
- `:focus-visible` 清晰可见；纯图标都有 `aria-label` 和 hover tooltip；环形用量用 `role=progressbar`，提供 `aria-valuenow`、`aria-valuetext`。成功动作不弹多余 toast，错误贴近当前区域。

## 实现边界与验收

涉及 `panel.tsx/.css`、`avatar.tsx/.css`、共享契约和 main 的窗口 shape；视图组件与状态、数据契约分离。当前只写标准，组件改动以此为准。用户负责可见窗口验收；代码层做类型检查和能验证状态逻辑的最小测试，不启动 GUI。

需用户验证：① 左键开关/右键选项与退出、中键余额互不干扰；② 放大/关闭时角色不动且气泡无闪影；③ 5 个标签只是快捷切换，第 6 个仍能创建并在会话库找到；④ 输入区加号新建、模型弹层、用量环、输入框独立放大、发送/停止；⑤ 图标 tooltip、键盘与中文输入法；⑥ 归档/恢复/删除不串会话。
